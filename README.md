# 🪙 Cryptocurrency Price Prediction & Analysis

A data science project focused on cleaning historical cryptocurrency price data, conducting Exploratory Data Analysis (EDA) through visual trends, and building a predictive Machine Learning model using **Python** and **Scikit-Learn** in a **Jupyter Notebook**.

---

## ✨ Project Highlights

- **🧹 Data Cleaning & Preprocessing:** Handled missing values, formatted dates, scaled numerical features, and prepared time-series data using **Pandas** and **NumPy**.
- **📊 Exploratory Data Analysis (EDA):** Visualized price trends, moving averages, and correlation matrices using **Matplotlib** and **Seaborn**.
- **🤖 Machine Learning Model:** Built, trained, and evaluated a regression/predictive model using **Scikit-Learn** to forecast price movements.
- **📈 Model Performance Evaluation:** Analyzed actual vs. predicted price metrics within the Jupyter Notebook environment.

---

## 🛠️ Tech Stack & Tools

- **Environment:** Jupyter Notebook
- **Language:** Python 3.x
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-Learn (`sklearn`)
